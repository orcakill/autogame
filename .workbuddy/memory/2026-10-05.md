## 排查好友协战（impl_friends.friends_fight）

### 结论：好友协战战斗循环从未真正执行，每天都是空跑

**证据（全量日志统计 logs/bat/main_day_all_2026*.log）：**
- 「本轮好友协战...挑战0次，胜利0次，失败0次」— 09-27 至 10-04 每天每次都是 0 次
- 「解锁阵容」「锁定阵容」「协战式神」「白蛋」「准备」这 5 个模板识别成功次数 10 天全部为 0
- 「无解锁阵容，无锁定阵容,退出」每轮必现（09-27:16次 / 10-04:8次）

**根因（src/service/impl_onmyoji_service/impl_friends.py 第 89-105 行）：**
```python
for i in range(16):
    if i == 0:
        is_unlock = ImageService.touch(Onmyoji.soul_BQ_JSZR, wait=3)   # 解锁阵容 → False
        if not is_unlock:
            is_unlock = ImageService.touch(Onmyoji.soul_BQ_JSZR, wait=3)  # 再试 → False
            is_lock = ImageService.exists(Onmyoji.soul_BQ_SDZR, wait=3)   # 锁定阵容 → False
            if not is_unlock and not is_lock:
                break   # ← 第1次就 break，16 次循环全废
```
`soul_BQ_JSZR`(解锁阵容) / `soul_BQ_SDZR`(锁定阵容) 在当前游戏界面识别不到（SIFT 阈值 0.7，模板为小锁形图标 29×43~96×109，特征点少）。模板图最近在 2026-05-09 更新过但仍失败。

**注意**：`ImageService.touch(..., wait=N)` 的 `wait` 是点击前固定 sleep，不是重试时长（见 impl_exists.py 第 55 行 `time.sleep(wait)`，第 97 行未识别返回 False 且不点击）。

**对照**：同一游戏页面（八岐大蛇御魂）在魂十一任务（02:32~02:39）里「挑战/自动」模板识别正常，说明仅协战所需这套模板识别失败。

**待办/修复方向**：
1. 给「解锁/锁定阵容」识别加容错（真识别不到应视为已有阵容继续挑战，而不是 break）
2. `touch` 返回值语义需澄清（False = 未识别而非点击失败）
3. 更新协战相关模板图 / 调整 SIFT 阈值，或改用模板匹配兜底
4. 记录：挑战次数为 0 时应告警，不应记为「好友协战」正常完成
